# 🧠 Smriti-Setu: Cognitive & NER AI Gaming Platform

Welcome to the **Smriti-Setu** project repository! This repository is organized as a clean monorepo with separate `frontend` and `backend` modules so frontend and backend developers can work independently.

---

## 📁 Repository Structure

```
NER AI gaming platfrom/
├── 📂 frontend/            # React + TypeScript + Vite + Tailwind CSS Web Application
│   ├── src/               # UI components, pages, stores, and activities
│   ├── index.html
│   ├── vite.config.ts
│   └── package.json
│
├── 📂 backend/             # Node.js + Express + TypeScript Backend API Server
│   ├── src/               # API routes, controllers, and services
│   ├── tsconfig.json
│   └── package.json
│
└── 📄 README.md
```

---

## 🚀 Quick Start Guide

### 🎨 1. Frontend Development (`/frontend`)
```bash
cd frontend
npm install
npm run dev
```
* Local URL: `http://localhost:3000/`

### ⚙️ 2. Backend Development (`/backend`)
```bash
cd backend
npm install
npm run dev
```
* API Server: `http://localhost:5000/`
